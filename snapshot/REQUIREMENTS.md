# 规范性要求 v3.0（974 nm 单基线）

## 1. 目标与结论有效范围

在 COMSOL 6.4 上建立**一个**可参数化重建、可复算、可追溯的三维基线模型：芯片等效辐射场（974 nm）→ 空气间隙 → 光纤端部一体化楔形圆弧透镜 → HI1060 FLEX 均匀（等效阶跃）光纤，输出 HE11 耦合效率、损失账本与数值验证证据。不能把"收敛了"代替物理正确；不设人为最低效率目标。仅允许"在列明假设及数值范围内验证"的结论；实验状态始终独立（NOT_PERFORMED）。本版回答"该基线在此假设集下数值上如何"，不回答"该形状是否最优/公差是否足够/宽谱下如何"。

## 3. 规范模型与代表工况

- 唯一规范模型：建议文件名 ld974_lensfiber_ewfd.mph（最终名以冻结配置为准），含 2D 模态分量与 3D 全链路分量及各自 study；S02/S03 可作为同一模型内 study 或辅助工作副本执行，但交付按单规范模型盘点（ADR-308）。
- BASE：974 nm、名义几何（45°/R3.25/间隙 5.65 初值）、F_NOM、x 偏振、像散 0、无膜。
- LAT1：在 BASE 上光纤（含纤端透镜整体）横向平移 dx=+1.0 um（取自 v2 scan_plan 保留初值），仅作数值稳健性/收敛诊断，不构成公差结论。
- gate 报告中每个 gate 标注 APPLICABLE / NOT_APPLICABLE(ADR-304) / DEFERRED(ADR-305)，保留原 id 与限值。
- 文中 ADR-3xx 编号对应 CHANGELOG.md 的决策台账；总体范围决策见 docs/adr/ADR-003-974-lensed-fiber.md，采样机器记录见 configs/adr/ADR-0001-sampling-974-baseline.json。

## 4. 参数有效域与自动重建（本版）

合法域 = 单一基线及其参数化重建：正波长/尺寸、NA>0 且 ncore>nclad、源功率>0、楔形/圆弧几何自洽（无自交叠、边厚>0）、源面/端口/PML 不错误穿入异材料、平移后全部几何在域内。区分"物理输入合法、几何可建、数值收敛、验证通过"四件事。回归：BASE；LAT1；非法两例（负 R、楔形自交叠）在求解前被拒并留记录。任何扩展（波长点、公差、形状）须新 ADR + 相应回归。

## 5. 里程碑与状态

M1=S00–S04：环境、输入、974 nm 模态与源、局部入纤基准可复算。M2=S05–S06：单一规范模型完整求解与账本闭合。M3=S09：独立审查、清空解重算、单模型制品可取回与报告。里程碑是增量交付；M3 完成也不代表实验验证或远端同步完成。阶段状态 NOT_STARTED/RUNNING/NEEDS_REVIEW/VALIDATED/BLOCKED/FAILED；同步状态 LOCAL_ONLY/COMMITTED/PUSHED/VERIFIED_REMOTE/REMOTE_UNCONFIGURED；审查与实验状态独立。

## 6. 本版明确排除（激活须新 ADR）

形状对比与参数优化；公差扫描（S07 后移，G21 DEFERRED）；宽谱/光谱加权与截止端点扫描（S08 后移，G07b/G12a/G12b/G13 DEFERRED）；EWBE 与跨模型传场门槛（G10/G11a/G11b 对单模型路由 NOT_APPLICABLE）；v2 双透镜 C0/C1/C2 分支（保留在 legacy，只读）；LD 内部输运/腔/热模型；光纤端面镀膜；实验拟合与生产统计。二维纵截面、只有解析高斯接收、裸圆柱或球透镜演示不能替代正式交付。

## 7. 原始与设计信息的地位

U=用户资料（U1 截图、U2 PDF、974 nm 工况指令），R=可核验公开来源（Malitson 色散、Corning 2010 版资料），A=器件类比（45°/R3.25/5.65 初值来自其他 980 nm 研究、快轴 30°），E=工程假设（全角 FWHM 约定、均匀阶跃剖面、n_air=1、无膜平端、参考温度、谱形），D=推导，N=数值选择（网格因子、PML 起点、搜索候选数）。楔形/圆弧/间隙初值不是目标产品规格；本包不声称还原真实器件。
