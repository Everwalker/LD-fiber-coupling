# 验收、误差预算与证据（v3）

规范阈值的机器可读数值来源是 configs/gates.json。保留 v2 的 gate ID、操作、limit 和单位；适用性按 ADR-003 区分，G20 的制品范围改为单模型。适用、后移、不适用均不代表已经通过。**效率绝对差 0.005 = 0.5 个百分点，不是相对 0.5%**；标注 relative 的量才用相对差。

## 0. 本包的“第一版代表工况”定义（采样数量的唯一基准）

BASE = 974 nm；S_FF 源（6 度/30 度全角 FWHM 假设，x 偏振假设）；F_NOM 光纤分支；楔形几何名义 alpha=45 度、Rtip=3.25 um、gap=5.65 um；无膜、k=0、无倾斜。LAT1 是 BASE 上 dx=+1 um 的合法参数化回归，不是公差或方案比较。G08/G09/G15 对两点执行；其他检查按表与相应阶段合同执行，不改任何 limit。

## 2. 验证分层（与 v2 相同，不得互替）

包工具单测（preflight+unittest，不启动 COMSOL）→ 物理单元（空域角谱、Fresnel、均匀光纤自传输、可微背景场残差）→ 完整模型（实际复场、源分母、两偏振投影、账本、网格/域检查）→ 后移的工程敏感性（本包无）→ 交接复现（清解重算、独立审查、取回字节校验）。

## 3. 974 nm 特有检查

- 模式计数：解析参考 V(974)≈2.4126>2.4048（F_NOM）；实际模态求法必须报告是否存在弱导高阶及分类证据；eta 只取 HE11 子空间，高阶单列。
- 近截止投影条件数：Gram 条件数与正定性写入证据。
- 声明边界：不得写“974 nm 单模保证”“宽谱 eta”“0.6 W*eta 是实测”“文献 81.7% 可类比本项目”。可以写：在列明假设（30 度快轴类比、名义楔形初值、固定外部源、无膜）与 974 nm 单波长内，哪些数值门槛通过。

## 4. 证据与机械校验

每阶段 stage_result.json、最终 validation_report.json、reviews/reruns 字段参考 v2；本包提供的结构以 schemas/ 和 templates/ 实际文件为准。本版尚未提供 COMSOL 结果总校验器，执行者须在真实结果出现时按本合同实现并验证，不能把软件预检当作该校验器。数值字段不用 NaN/Inf，未计算用 null 且 status 非 PASS；布尔门槛 value 必须 true。每个 gate 关联真实证据路径与 SHA。源码/命令、hash、job、数据集、独立审查、清解重算、远端同步各自独立记录，不互相代替；结构检查也不能替代独立物理审查。

## 5. 误差与敏感性声明

总误差预算分别记录数值离散/域-PML/角谱/求解器残差尺度；不无依据平方和成统计置信。输入假设（30 度、楔形初值）是情景范围不是概率分布；无样本统计不报良率或置信区间。公差阈值区间（0.5/1 dB crossing、位置不确定度 0.05/0.5 um/0.1 度等 G21 工程指标）整体后移，原阈值数值不动。
