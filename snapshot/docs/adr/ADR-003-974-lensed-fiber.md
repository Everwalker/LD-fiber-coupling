# ADR-003 | 974 nm 单一基线：楔形圆弧一体化纤端透镜取代两透镜光路，敏感性阶段后移

状态：ACCEPTED_USER_SCOPE（用户于 2026-11-11 确认目标与调整方向，并要求生成新版工作包）；工作包独立审查和任何 COMSOL 数值验证均另行记录，不能由此状态代替。

背景与证据：
v2 包（docs/、configs/、代码）规定了两片非球面透镜完整光路（S06 coupler_ewbe）、公差扫描（S07）、宽谱/截止端点扫描（S08）与四模型制品（G20），波长代表点为 970 nm。用户于 2026-11-11 明确新目标：一个真实 COMSOL 6.4 可求解、可参数化的 3D 模型，链路为芯片等效辐射场→空气→光纤端部一体化楔形圆弧透镜→HI1060 FLEX 均匀光纤；974 nm 为用户指定仿真工况；只生成新版工作包。楔形示意半角 45 度、顶端 R 3.25 um、轴向间隙 5.65 um 仅来源于其他 980 nm 研究（[R_LIU]）的初值，不是目标产品规格也不是最优值。

备选方案：
1. 沿用 v2 两透镜 + 全比较计划（被用户最新指令覆写，拒绝）。
2. 在同一包里同时做形状对比/优化/公差/宽谱（用户明确“一个基线”，拒绝）。
3. 本 ADR：单基线 + 阶段后移 + 采样数量按代表工况收缩（采纳）。

对原规范/物理范围/验收/成本/安全边界的影响：
- 覆写范围（仅对本 v3 包）：v2 R-10/R-11（EWBE 长光路与两透镜 C0/C1/C2 分支）、R-13/R-14（公差与倾斜）、R-15（宽谱功率加权）、R-19（四模型交付）不再是本包交付内容；其数值与定义全部冻结保留，留给后续阶段/包，不删除。
- 保留不变：U1 原值（967/970/973 nm、600 mW、水平远场典型 6 度、光谱 10/15/20 nm、芯片尺寸/厚度）、U2 原值（930±40 nm 截止、工作>980、MFD 4.0±0.3@980、NA 0.22、芯径 3.4 μm、标准包层 125±0.5 μm 等）与原始文件；水平轴对应慢轴及全角定义为工程约定，快轴 30 度为类比；所有保留的 gate 数值阈值不改。
- 代表工况为 974 nm、S_FF、F_NOM、名义楔形几何、无膜、无倾斜的 BASE，以及仅用于参数化/数值回归的 LAT1（dx=+1 μm）。G15 对 BASE 和 LAT1 两点清解重算；G18 包括合法重建与至少两例非法输入拦截；G08/G09 的原限值与网格/域检查保留，并在两代表点执行。这些回归不构成形状对比、优化或公差结论。
- gate 语义变更（ID/阈值不变）：G20 由“四模型与复场制品”改为“单模型制品与配套复场/日志/源码可取回哈希一致”；G14 要求根据实际几何、源注入和边界验证来声明已计入的反射，不声称自动涵盖所有反射，固定外部源不含 LD 腔反馈。G10/G11a/G11b 在单域路线不适用，若经批准使用受控分段则重新激活；G17 仍须证明受控源注入，背景场可微性按实际选用的方法判定。
- 阶段语义：S00–S09 ID 与 gate 归属仍与 common 一致；S05 跨接口条件对基线不适用（条件分支）；S06 由两透镜改为楔形圆弧纤端单体模型；S07/S08 后移（不是取消，不放松门槛）。
- 命令契约更新为 python -m tools.preflight 与 python -m unittest discover -s tests -v（均不启动 COMSOL），取代 v2 run_checks 入口名称。
- 物理边界：974 nm 高于厂家截止区间 890–970 nm 的上界、低于标称工作范围>980 nm 下界；F_NOM 阶跃等效又把 974 nm 判为近截止可能多模；因此本包禁止“单模保证”类结论，以 S02 实际模态为准。文献（[R_LIU] 980 nm 楔形透镜光纤研究，含其实验效率值）只作方法与初值来源引用，不是本项目结果。
- 成本/资源：单体 EWFD 模型 DOF 受 3 um 级曲率与微米纤维截面驱动；已预登记受控分段 fallback 及其取证要求，不预防性降级。

建议与理由：
用户指令是最新且明确的需求定义；新包以最小可行科学链（一个模型 + 一个代表工况 + 数值有效性门槛）先建立真实可复算基线，把敏感性工作（公差/宽谱）以冻结定义的形式后移，既守住原阈值又不冒充已验证范围。
