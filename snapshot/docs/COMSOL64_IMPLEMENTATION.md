# COMSOL 6.4 实施映射与运行时取证（v3：单体楔形纤端模型）

命令契约（v3，均不启动 COMSOL）：

    python -m tools.preflight
    python -m unittest discover -s tests -v

preflight 只做配置/参数/来源/计划一致性与文件边界检查；unittest 只覆盖解析、投影、几何公式、哈希与记录工具。两者通过不等于任何 COMSOL 能力或科学结果存在。COMSOL 动作默认 MCP-only；绕过 MCP 的 Java/MATLAB/CLI 直连须用户批准。本包尚无任何有效科学求解；能力、许可、MCP 必须经 S00 实证，不能编造。

## 1. 软件与控制通道（S00 实证清单）

必须实际读出并去敏保存：COMSOL 6.4 build、Wave Optics 产品可用性、许可形态；MCP 工具列表、参数 schema、读写权限；模型保存/重开 smoke。只声明“安装了 COMSOL”不算许可检查。单体模型所需能力清单（能力描述，不是臆造工具名）：

- 创建/保存/关闭/重开 .mph；参数与变量读写；
- 创建参数化几何（工作平面、圆弧/直线/布尔、 extrude/相交）并读取域/面计数；
- 语义命名选择读写；材料与物理节点列举；
- 添加 2D 模态分析 study 与 3D 频域 study；选择求解数据集；
- 启动长任务、查询/取消已知 job；清空解保留设置；
- 导出截面完整复数 E/H 与表格；读取 DOF/日志/求解器信息。

任一能力缺失就记录能力缺口并阻塞对应步骤，不得静默跳过失败节点。官方 API 取证流程沿用 v2：实际 6.4 最小模型创建节点 → 允许通道保存/导出设置 → 比对属性 → 同通道重建 → 核对树。文档中的展示标签不等于已验证属性名；所有 node/tag 以实录为准。

## 2. 单一模型蓝图（G20 制品对象，名称以最终配置为准）

建议模型名：ld974_lensfiber_ewfd.mph（单体 mph，包含三维模型及所需模态研究；独立二维模态组件可作为辅助）：

组件 3D（主模型）：
- Geometry：全局参数 lambda=974[nm]、gap_um、alpha_deg、Rtip_um、a_core_um=1.7、b_clad_num_um（起点 15，预留扩展至实际 62.5 的参数）、z_len_fiber、x_half_width、air_box、pml 壳。y–z 工作平面上用圆（半径 Rtip，圆心 (y=0,z=Rtip) 的下弧）+ 两条过切点 (±y_t,z_t) 斜率 ±cot(alpha) 的楔面线 + 外边界构造端面剖面，与包层矩形布尔并；沿 x 平移不变（拉伸），与芯/包层柱体相交。重建后断言：域计数与预期一致、每个命名选择非空、弧/楔/柱交线存在、mode_plane 截面为均匀同材环形、PML 与透镜外边界有均匀空气间隔。
- Physics：EWFD（频域，974 nm 单频）。材料：空气 n=1；玻璃 Malitson 色散（表达式，6.4 实际支持的函数形式实录）或按实录支持的插值；k=0。PML 外层；下游吸收段与 Numeric Port 须经验证，端口的 Boundary Mode Analysis 以实际三维端口截面为准。独立二维模态研究可供核对，但不可未经文档及运行证据就假定数值端口能直接引用另一个组件的模态解。源注入按第 3 节决策树。[C64_PORT]
- 网格：玻璃内起始最大单元约 lambda_glass/5≈0.134 um；Rtip 曲率区与芯包界更细；PML 映射层；三网格 h=1/0.75/0.55 仅作数值验证起点（属数值有效性检查，不是设计对比）。每级记录 DOF、最差网格质量、内存峰值、耗时。

组件 2D（模态）：与 mode_plane 相同截面（core/clad/数值外域+PML 3 um 起点），EWFD three-component Mode Analysis；在 974 nm 搜 8–12 候选并在接近 nclad 处追加；导出 HE11 两偏振与高阶候选的完整复场、neff、分类证据。G04a/G04b 只在本截面执行（974 nm）。

同一 .mph 同一时刻只允许一个写入者；模式组件与主组件在同一 mph 内以保证 BMA/数据集引用可审计。

## 3. 源注入与可微背景场：按选法判定的决策树

优先级 A（默认）：EWFD 散射场公式 + 可微三维背景场。背景场由 FIELD_CONTRACT 第 5 节的矢量角谱 PWE 重构以显式三维表达式实现（COMSOL 内解析表达式/解析函数叠加，或在可微性实证后的受限截断求和）；约束：三维 Ebackground 必须在需要区域可微，不能把二维表通过 General Extrusion 等耦合算子设为背景 [C64_EWFD]。验收证据：无散射体（删除透镜/光纤）时空域残差与解析角谱对照、网格加密收敛、source_plane 功率与归一化检查（G03a）。可微性本身是选型门槛：若截断谱求和不可微或表达式规模导致不可解，记录证据后降级。

优先级 B（备选）：受控等效源/注入边界在 source_plane 实现同一辐射场：必须保留入射-返回分离（输入端允许反射离开，不得用强制总 E 边界消反射）、无源空域测试、与独立投影对照。只有实际 6.4/MCP 实现并独立审查通过才可采用；不把示意式当现成 API。

优先级 C（受控分段 fallback，仅当真实内存/硬件受阻）：将模型分为“源+楔形端面局部 EWFD 子域”与“下游光纤接收 EWFD/端口子域”，界面处按 FIELD_CONTRACT 第 3 节传场合同执行，G10/G11a/G11b/G17 全部激活并独立审查。触发条件必须留存（DOF、RAM 峰值、失败日志），不得预防性采用；不得通过过粗芯区网格或删除物理项冒充资源优化。若界面一侧需长程传播才可行，EWBE 蓝图（v2 coupler 模型）只作历史参考，采用其载波/MBC 合同 [C64_EWBE/C64_MBC] 必须重新实证。

## 4. 端口、模式与 974 nm 近截止处理

mode_plane 上 Numeric Port 先对该三维端口截面做 BMA，再进行 Frequency Domain 驱动；截面覆盖芯与完整模式尾部，不只芯圆面。独立二维模态结果用于分类和核对，跨组件直接映射须有官方文档与实际运行证据。正式自由空间接收求解时端口不激励，仅在 B3 标定（均匀光纤自传输/互易/端口与投影比较）主动激励。PoutMPort_N 聚合可能含 HE11 之外模式：只取经模式识别确认的两 HE11 功率，其他导模（近截止 LP11 类）单列；不得看到 Matched 就当 Fundamental。自动端口效率只用于核对，不改本项目分母。

## 5. 选择、几何、网格与命名

语义命名沿用 v2 原则：core_domain、clad_domain、air_domain、lens_surface（楔+弧端面）、facet_plane、source_monitor、mode_port、pml_domains 等；几何生成选择优先，禁止跨重建固定裸实体号。每次重建断言非空、计数范围、材料归属、参考面 z/法向。

## 6. 求解、复算与记录

先 pilot 再正式。记录 study 方案、linear solver、预条件、容差、DOF、内存峰值、真实开始/结束时间、job_id。参数改变后验证 study 所取模态/数据集不是旧解。干净复算（G15，采样数量按 ADR-003 为一个代表工况即 974 nm 名义）：冻结检查点 → 新会话重开 → 清解 → 重跑 BMA+驱动 study → 导出 → 与原 case 对照，阈值 0.001 不变。干净重建：从源码/调用序列重建 mph 再求解，至少名义工况 + 非法输入拦截回归（负 Rtip、gap<=0、几何相交失败在求解前被拒并留记录，G18 采样数量同步缩减为本包强制情景集）。

验证器不能把失败工况排除后只算均值；失败工况保留 null+原因。构建器不隐藏求解，求解器不改参数，导出器不换数据集。
