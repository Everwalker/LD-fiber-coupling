# 物理模型与参数合同（v3：974 nm 楔形圆弧纤端一体化模型）

本文件与 v3 configs/parameters.json 共同定义当前假设；来源索引见 references/sources.json。来源等级沿用 U=用户资料、R=可核验公开原始来源、A=器件类比、E=工程假设、D=推导、N=数值选择；L980_INIT 是来自其他 980 nm 器件研究的初值标签。本包只有一个基线工况；不做透镜形状对比、参数优化、公差扫描或宽谱扫描。

## 0. 唯一目标链路

一个真实 COMSOL 6.4 可求解、可参数化的三维单体模型：

    芯片等效矢量角谱辐射源（974 nm） → 空气间隙 → 光纤端部一体化楔形+圆弧透镜 → HI1060 FLEX 均匀光纤（芯/包层）

974 nm 是用户指定的仿真工况。原 U1 的 967/970/973 nm、600 mW、慢轴 6 度，原 U2 的 930±40 nm 截止、工作波长 >980 nm 与全部原始文件原样保留、冻结登记；本阶段不执行宽谱或截止端点求解（S08 后移，见 EXECUTION_AND_RECOVERY），因此不得声称对这些值完成了 v3 求解验证。快轴 30 度仅是旧任务类比假设（grade A，来源 A_FAST30），不是本型号实测或厂家公差。

## 1. 坐标、时间、功率及模式约定

全局右手坐标：x=水平慢轴，y=垂直快轴，z=传播方向。该轴序与 v2 PHYSICS.md 及既有 angular_spectrum.py 保持一致；任何代码或文档不得再使用"y=慢轴"的旧别名。透镜剖面在 y–z（快轴）平面内变化，沿 x（慢轴）方向平移不变。

时间约定 exp(+i*omega*t)，正向平面波 exp(-i*k*z)。COMSOL 端口的入射/出射模方向必须从实际箭头与自投影验证，不仅按 beta 正负猜测。时间平均功率 P=0.5*Re*Int(E x H*)·n dA；E 为 V/m，H 为 A/m，面积 m^2，P 为 W。二维横截面本征模只用于重建三维单位功率，不把二维纵截面 W/m 当 W。

主指标 eta_HE11=(P_HE11_pol1+P_HE11_pol2)/P_LD_out。两 HE11 偏振须功率正交，否则用 FIELD_CONTRACT 的 Gram 子空间投影。固定 P_LD_out=1 W 计算；0.600 W * eta 仅是把名义 600 mW 假设为该单色工况时的等效换算，不得表述为实测 974 nm 功率、宽谱积分效率或产品实测耦合功率。净纤芯截面通量、整个包层通量、几何截获率、单偏振效率是辅助量，不能替代主指标；总截面通量不等于 HE11。

## 3. 楔形+圆弧纤端：可复建构造假设

本节几何是本包定义的构造假设，供重建与复算；不声称等于任何论文实物、不是文献给出的唯一剖面、不是已制造实体。

### 3.1 剖面公式（在 y–z 平面内）

光纤轴为 z，端头顶点位于 z=0，玻璃位于 z>=f(y)。alpha 为楔面相对 +z 轴的半楔角，Rtip 为顶端圆柱弧半径：

    y_t = Rtip * cos(alpha)
    z_t = Rtip * (1 - sin(alpha))
    |y| <= y_t:  f(y) = Rtip - sqrt(Rtip^2 - y^2)
    |y| >  y_t:  f(y) = z_t + cot(alpha) * (|y| - y_t)

在 y_t 处弧面导数 y/sqrt(Rtip^2-y^2) 与楔面斜率 cot(alpha) 相等，剖面 C1 连续。该表面绕 x（慢轴）方向平移不变（圆柱弧 + 平面楔棱），与真实纤芯/包层圆柱相交形成透镜端面。参数组：alpha_deg=45、Rtip_um=3.25、以及芯半径 a=1.7 um、数值包层半径 b_num（起点 15 um，可扩）、几何长度参数。

### 3.2 名义切点数值（本包解析计算，仅供重建对照）

alpha=45 度、Rtip=3.25 um 时：y_t≈2.29810 um，z_t≈0.95190 um。弧过原点 (y=0,z=0)，即顶点是玻璃端面最靠源的一侧点；楔面向外上方延伸至与包层外边界相交。几何生成后必须实际核验：域计数与连通性、弧/楔/柱面交线、端口所在截面是否均匀材料、PML 与透镜外边界的间隙。不得只按边编号判断闭合，应保留环形/分段面片的真实材料分割情形。

### 3.3 源面与间隙定义

源参考面取平面 z=-gap，默认 gap=5.65 um，即源参考面到端头顶点（z=0）的轴向距离。这是本包的几何定义；论文中轴向距离与此定义是否完全一致尚待逐图核实，不能把两者的等价关系当作已知。若发现定义不同，先以 ADR 记录影响再改参，不得静默换定义。gap、alpha、Rtip 均为可重建参数，本阶段只解名义一组，另做规定的 LAT1 数值回归，不做扫描。

## 4. 材料、光纤与 974 nm 近截止

熔融石英色散沿用 Malitson 公式 [R_MALITSON]：n^2-1 = 0.6961663*u^2/(u^2-0.0684043^2) + 0.4079426*u^2/(u^2-0.1162414^2) + 0.8974794*u^2/(u^2-9.896161^2)，u=lambda/1um。本包解析计算 n(974 nm)≈1.4507498、n(970 nm)≈1.4508018、n(980 nm)≈1.4506723。这只是纯 SiO2 参考，不代表掺杂芯剖面。

光纤分支定义保持 v2：F_NOM：a=1.7 um、NA=0.22、ncore=sqrt(nclad^2+NA^2)（恒 NA 阶跃等效，不是 Corning 剖面反演）。F_CUTOFF 族：NA=2.4048255577*lambda_c/(2*pi*a)，lambda_c=890/930/970 nm；本阶段仅 F_NOM 参与基线，F_CUTOFF930 分支定义冻结留给后续。

974 nm 近截止事实（本包解析值，待 S02 模态实证）：F_NOM 的弱导 LP11 截止波长 lambda_c=2*pi*a*NA/2.4048255577≈977.165 nm，故 V(974)≈2.4126>2.4048：在等效阶跃模型下 974 nm 处于近截止，可能支持弱导高阶模。厂家规格给出截止 930±40 nm（名义上界 970 nm）与"工作 >980 nm"要求；930±40 nm 的数学区间是 890–970 nm；974 nm 高于该截止区间的上界（970 nm），同时又低于厂家标称工作范围（>980 nm）的下界，即处在截止不确定区间之外、但也不在厂家标称工作范围内的夹缝区。与此并存，F_NOM 阶跃等效给出的截止波长 977.165 nm 把 974 nm 判为近截止、可能多模：两套判断不一致，且都不能保证实际单模。S02 必须在 974 nm 实际求模：HE11 两偏振子空间确认 + 8–12 候选搜索与接近 nclad 追加搜索 + 高阶候选分类记录；若发现弱导 LP11 类模式，其耦合功率单独入账，不得并入 HE11，也不得据此断言厂家光纤规格错误。F_CUTOFF930 分支的 V(974)≈2.2962 为单模对照，仅作定义留给后续。

二维模态域：core a=1.7 um，数值包层半径起点 15 um，PML 3 um；实际标准包层半径 62.5 um。近截止高阶可能需要扩大数值域并检查外域/PML 敏感性；做不到就把高阶分类记为未确定，不得以 PML 伪模充数。厂家 MFD 4.0±0.3 um@980 nm 的定义未完全给出，本包输出高斯拟合与二阶矩等多定义对照，不混用。

## 5. 源合同（974 nm 代表工况）

源分支定义保留 v2 的 S_FF、S_MFD_E2、S_MFD_FWHM；本阶段代表工况只执行 S_FF，另两分支仅冻结定义不求解（采样数量变更见 ADR-003）。

S_FF：wx=lambda*sqrt(2ln2)/(pi*Theta_x)，wy 同式。974 nm、6 度/30 度（全角 FWHM 约定）得 wx≈3.48585 um、wy≈0.69717 um。这只是角谱拟合初值，不是"实测束腰"。矢量角谱合同不变：k=2*pi*n/lambda，传播谱域 kx^2+ky^2<k^2，kz=sqrt(k^2-kx^2-ky^2)，A=exp[-(wx^2*kx^2+wy^2*ky^2)/4]，u=e_x-khat*(khat·e_x)，Etilde=A*u，Htilde=khat x Etilde/Z，合成 exp[-i(kx*x+ky*y+kz*z)]，同一傅里叶归一化。这是辐射等效源，不包含 LD 端面倏逝场与腔内反馈改变。

角宽观测量定义沿用 v2：远场辐射功率密度 dP/dOmega 在主轴平面截线的 FWHM（不是角度边缘积分 FWHM）。合成远场对目标 6/30 度误差≤1%（G03b 阈值不变）。先在扩大源参考面上确认捕获≥99.9% 辐射功率再归一 1 W；两个传播平面功率差≤0.5%。偏振假设主 x、对照 y；用户资料未给偏振，不得把任一偏振方向标为实测。

## 6. 反射、功率账本与标签

单体频域模型在求解域内相干包含端面/楔面界的反射与域内多次反射；输入侧开放边界允许反射离开计算域。源为固定外部场：模型不包含反射回 LD 腔后对源谱/模/功率的反馈改变。结论标签 FIXED_EXTERNAL_SOURCE_FULL_DOMAIN：不得把本模型说成"LD 腔反馈预测"，也不得像 v2 级联模型那样需要 SINGLE_PASS 近似声明（单体模型无级联裁剪；该边界改为固定源边界）。

输入账本（同一参考面区域分割闭合）：

    1 W(源正向) = 返回源侧 + P_HE11(两偏振) + 其他导模(近截止高阶，单列) + 辐射(由 PML 数值离域吸收) + 数值残差

玻璃 k=0 无体吸收；PML 是数值离域通量，不与同一穿界通量重复加；端口功率与 PML 吸收不重复加。失配功率不丢弃、反射不重复扣。

同介质标量高斯重叠、偏移、倾角、束腰失配解析式沿用 v2 第 8 节，仅作为解析参考；由包内 Python 计算并标记身份。以下都不是本项目 COMSOL 结果：解析公式输出、文献（含 [R_LIU] 的实验 81.7% 等）、其他包/历史缓存、示意图。不存在的值写 null+原因，不写 0 冒充。
