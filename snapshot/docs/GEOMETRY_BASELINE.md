# 纤端楔形圆弧基线的可重建定义

本页定义一个便于第一版实施和审查的**几何假设**，不是厂商面形、加工记录，也不声称与参考论文器件完全相同。最终形状由 COMSOL 实际几何构建、选择集、网格和数值解验证；公式本身不是仿真结果。

## 坐标和材料

- `z` 为 LD 指向光纤的传播方向，`x` 为水平慢轴，`y` 为垂直快轴。楔面随 `y` 改变，沿 `x` 方向延伸；这与原有角谱源的坐标约定一致。
- 纤端光轴处顶点取 `z=0`，LD 等效出射参考面取 `z=-gap`；`gap=5.65[um]` 是参考文献启发的示意初值，不是实际测量或本器件优化结果。
- 名义光纤芯半径 `a=1.7[um]`，标准包层半径 `b=62.5[um]`。保留连续的芯/包层：端面通过裁切光纤本体形成，不新增一块悬空透镜。芯/包层折射率剖面和端面加工引起的变化未知，本版采用明确记录的等效阶跃假设。
- 名义无膜只是一项假设。空气—玻璃折射与反射须包含在实际求解模型中；固定外部源不表示预测激光器腔内光反馈。

## 一种圆弧与楔面相切的参数化剖面

`R=3.25[um]` 为圆弧半径，`alpha=45[deg]` 是楔面与光纤 `+z` 轴之间的半角；完整楔角为 `2*alpha`。令

```text
yt = R*cos(alpha)
zt = R*(1-sin(alpha))

f(y) = R - sqrt(R^2-y^2)                    |y| <= yt
     = zt + cot(alpha)*(|y|-yt)             |y| > yt
```

光纤材料取 `z >= f(y)`，再分别与实际芯、包层的圆柱形区域求交。圆弧和两侧直面在 `|y|=yt` 位置值及一阶斜率连续；其沿 `x` 外推形成一个圆柱圆弧顶和楔面。名义初值下 `yt≈2.2981[um]`、`zt≈0.9519[um]`。这仅是一个可复建的理想化剖面，真实熔融或研磨后的三维形状和芯部变化并未给出。

至少要求 `R>0`、`gap>0`、`0<alpha<90[deg]`、`0<a<b`；全部参数须有限，几何变化后重新验证选择集、介质连续性和无非法交叠。端口须位于面形之后**几何和材料沿端口法向不再变化的均匀截面**，并容纳完整的目标模式。

当本公式扩展到标准包层完整半径时，`f(62.5[um])≈61.15[um]`，三维计算域与网格成本可能较大。若为节省资源截断计算域，不得把被裁掉的边界或模态功率静默忽略：需说明所保留真实界面，并对截断、端口位置、PML及目标基模功率做收敛检查。没有实际计算前，不承诺该尺寸在当前机器上能求解。
