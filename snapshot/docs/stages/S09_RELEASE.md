# S09 | 独立审查、真实重算与单模型制品交接（974 单基线）

## 输入与前置

S00–S06 全部强制成果与原始日志/模型/场数据可取回；S07/S08 的 DEFERRED 登记已完成。不能仅凭 summary.csv 做最终审查。本版制品规模按 ADR-308 为**一个规范模型**（G20 语义：单模型与必要场/日志/配置制品可取回、哈希一致；判定仍为布尔，原限值不变）。

## 操作步骤

1. 汇总 gate 总表：每个 gate 标 APPLICABLE（含实测值）、NOT_APPLICABLE(ADR-304：G10/G11a/G11b)、DEFERRED(ADR-305：G21、G07b、G12a、G12b、G13)、NOT_STARTED/FAILED，并附 ADR 链接。遗漏项显式列出，不静默消失。
2. 代表工况最终数值验证 {BASE, LAT1}（ADR-306）：三网格效率最大绝对差 ≤0.005（G08）、域/PML/端口单因素变化 ≤0.003（G09），阈值数值沿用 v2，工况数量按代表点。输出 h/DOF/eta/Pin/P目标/闭合/解器误差与趋势解释；S05 的注入/空域检查在最终场范围复核一次。
3. fail-closed 回归（G18）：至少负 R_tip、楔形自交叠两例非法输入在求解前被拒并留记录；BASE 从源码/调用序列完整重建，验证选择、材料、源表达式、网格、study、模式数据集全部随参数更新，不残留旧解引用。
4. 冻结候选：代码 commit/哈希、canonical 参数、规范模型 SHA、BASE/LAT1 全部场与日志，生成 candidate_manifest 并取其 SHA 作审查对象。冻结后任何源/模型/场定义改动都出新候选并重审。
5. 独立子 agent 审查（G19）：审查者读规范、原始数值、模型树、变量、功率账本、失败表与关键复场，独立运行投影；结论仅 APPROVE/REQUEST_CHANGES/ESCALATE；记录实现者与审查者不同 run_id 与候选哈希。无法派生则 REVIEW_BLOCKED，不得自批，不得发布"已独立验收"。
6. 清空解重算（G15）：新 COMSOL 会话从冻结制品重开规范模型，证明依赖字节存在，清空解，重跑两点 study：BASE 与 LAT1（沿用 v2 两点规程；LAT1 仅作清空解/重建回归，不作公差或方案比较），导出新结果；效率绝对差 ≤0.001；保存清空动作、起止时间、日志、DOF 与新场哈希。另从源码重建至少 BASE。超时先查旧 job，不重复提交。
7. 制品与取回：整理一个规范模型、必要输入、字段元数据、原始场、重算指令与复算说明；每项制品有 artifact_id/角色/SHA/大小/6.4 build/代码哈希/访问范围/上传状态（当前 LOCAL_ONLY、URL=null）。远端未授权前不上传；获授权后按 GITHUB.md 矩阵执行并从远端取回校验 SHA、在执行机重开验证。仅链接存在不算取回验证。
8. 结构/数值自检（软件层）：运行 validation 结果检查工具与命令契约，得到 STRUCTURAL_NUMERIC_CHECK_PASS 只代表结构完整，不替代第 5 步独立审查；无真实结果时该检查应失败，这是预期。
9. 最终报告固定结构：数据与假设 → 实际模型与版本 → 通过/未通过/不适用/后移门槛 → BASE 与 LAT1 数值与不确定度 → 损失账本 → 敏感性（本版仅 LAT1 诊断）→ 实验缺口（NOT_PERFORMED）→ 复算与制品路径 → limitations（974 超出 U1 中心带与 U2 推荐工作带、快轴 30°/几何初值非规格、近截止高阶未定、均匀阶跃剖面假设、辐射等效源不含芯片端面效应）。四个状态轴分开：科学 / 独立审查 / 远端同步 / 实验。

## 必交付与有限验收

G08/G09/G15/G18/G19/G20（单模型语义）及全部本版适用 gate 通过；独立审查批准；清空解重算与源码重建证据；规范模型与必要制品哈希一致可取回。输出最终报告、candidate_manifest、validation 报告、reproduce 说明、制品索引。任何 DEFERRED/NOT_APPLICABLE 都不得写成"已通过"；本版通过也仅覆盖 974 nm 单基线假设集，不构成器件级、公差级或宽谱级结论。

## 失败处理

重算差 >0.001：查清空是否生效、数据集/模式引用是否残留、会话差异；保存两次原始日志，不覆盖旧结果。审查 REQUEST_CHANGES：按意见修复→新候选→重审。上传受阻：保留 LOCAL_ONLY 队列与恢复步骤，不反复重传巨型制品、不把受阻掩盖成已推送。

## 收尾（各阶段通用）

本报告身即最终收尾：evidence/stages/S09/ 汇总 stage_result.json 与全部引用；PROJECT_STATE.json、NEXT.md、handoff 更新到真实状态后，本包第一阶段工作结束，等待用户决定是否激活 S07/S08 或扩展范围（均需新 ADR）。
