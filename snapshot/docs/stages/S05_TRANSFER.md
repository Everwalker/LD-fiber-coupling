# S05 | 单模型注入、全域网格与 PML 可行性（v2 跨接口传场条件不适用）

## 输入与前置

S04 通过。ADR-304：本版为单一 3D EWFD 全域模型，不存在 EWBE→EWFD 跨模型传场，v2 S05 的接口条件（G10/G11a/G11b）对本版记 NOT_APPLICABLE——gate id 与限值保留在 gates.json，不删除、不改数值，只在 gate 报告标注并附 ADR。本阶段职责改写为：证明"等效源能在含纤端透镜的单一模型内受控注入且全域可解"。

## 操作步骤

1. 在 gate 报告中登记 G10/G11a/G11b=NOT_APPLICABLE(ADR-304)，并在 CHANGELOG 台账对应行补充实际执行日期与理由。其物理意图由后续单模型检查承接：注入一致性并入 G17 与 S06 账本（G07a），跨网格稳健性并入 G08/G09。
2. 在空空气域（无散射体）注入 S03 可微背景场/受控等效源：验证散射场残差≈随网格收敛到零、无超约束（不同时固定所有 E/H 边界分量）、无虚假边界反射被误读为物理散射。G17：可微背景场或等价受控注入证据完整（表达式可求导、空域残差、网格加密三件套）。
3. 建立缩小版楔形圆弧纤端几何（冻结初值缩比或截短纤段）做 pilot：估计 DOF 与内存（目标 ≤ 物理 RAM 70%、磁盘余量 ≥3 倍检查点体积），验证多尺度网格计划：空气域起步最大单元约介质波长/5，芯包界面、弧面与近场区加密，固定单元阶次并记录 h/DOF/最差网格质量/内存/耗时。
4. PML 配置验证：对空气域外边界与纤侧/下游 PML，用空域与平端情形检查物理波矢与伸缩坐标中相位梯度的含义；PML 厚度/层数/位置至少各一次单因素变化，观察注入功率与返回通量稳定。吸收域过小导致的截光必须与"数值稳定"区分（检查场尾部功率）。
5. 在前端面之前的空气监视面导出完整 E/H：比较监视面前向功率与 S03 的完整源归一化功率，并单列有限监视面外的裁剪功率，不对截获场重新归一。确认无反向分量混入前向账本（存在反射时净通量=Pf-Pb，不混用）。
6. 试验清空解保留 study/mesh 后重解 pilot；确认参数（间隙/半角/R）改动后网格、命名选择、study 数据集联动更新（为 S06 重建回归做准备）。

## 必交付与有限验收

空域注入验证记录与复场、pilot 模型与资源估计表、多尺度网格计划与实际 h/DOF 记录、PML 单因素记录、监视面功率对照、清空-重解记录、gate 报告中的 NOT_APPLICABLE 登记页。G17 通过；pilot 求解完成且资源可行。本阶段不产出最终器件效率结论。

## 失败处理

MCP 缺可微源/背景场注入能力：按 MCP_CAPABILITY 阻塞，给最小复现与所需能力清单，不绕 MCP、不靠重新归一化掩盖差异。DOF/内存超预算：先做截短域/对称缩减的可行性评估并如实标注适用边界，禁止用过粗芯区网格或删物理项冒充资源优化。3 次无新证据停止登记根因。
