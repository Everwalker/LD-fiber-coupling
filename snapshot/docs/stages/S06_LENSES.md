# S06 | 一体化楔形圆弧纤端与完整求解（原"双非球面光路"阶段改写）

## 输入与前置

S05 通过（G17、pilot、网格/PML 计划成立）。ADR-301：v2 的两非球面 C0/C1/C2 分支退出活动范围（legacy 只读，不迁移、不执行）；本版唯一实体 = HI1060 FLEX 均匀光纤 + 端部一体化楔形圆弧透镜（半角 45°、顶端 R3.25 um、无膜），装配 = 冻结间隙 5.65 um，波长 974 nm。理想变换/解析高斯匹配只作假设层参考，不代替实体求解。

## 操作步骤

1. 按冻结参数构建纤端几何：光纤圆柱 + 楔形（半角 45°）+ 顶端圆弧（R3.25 um）布尔并入同一实体；弧-楔-柱切接连续、无边翻转；检查边厚、包围盒、面朝向、自交叠。弧面几何离散/采样误差目标 ≤λ/50（974 nm），归档几何误差记录；不得只凭目视确认光滑。所有域/面用语义命名选择（fiber_core、fiber_clad、lens_solid、facet_arc、facet_wedge、monitor_pre_lens、pml_domains 等），禁止跨重建引用裸实体号。
2. 装配：S03 源参考面 → 空气间隙 5.65 um → 透镜圆弧顶端；下游纤段 + PML。参数化（gap、half_angle、R_tip、纤段长、域尺寸）由全局参数驱动；改参数重建后断言选择非空、计数正确、材料归属正确、监视面法向/z 正确。
3. 按 S05 网格计划生成三网格（h 因子 1/.75/.55 起点），记录 h/DOF/最差质量/内存/耗时；对 BASE 先解最粗网格 pilot 再解正式网格。求解为单一 3D EWFD 频域驱动 study，使用 S05 验证的注入方式。
4. 效率与账本：eta_HE11=(P_HE11,pol1+P_HE11,pol2)/P_LD,out，分母为 S03 冻结的源正向功率（计算 1 W；0.600 W×eta 仅作 974 nm 单色等效换算单独报，不写成实测 974 或宽谱功率）。监视面与光纤内下游截面用 S02 的 HE11 子空间投影；近截止高阶若被激励，其功率作为独立损失通道入账，不并入 HE11、也不丢弃。账本=返回源侧+HE11+其他导模/辐射+侧漏+真实吸收(k=0)+PML 数值通量，逐项不重复计；G07a：名义功率闭合相对误差 ≤0.005。
5. 反射范围声明（G14，条件化）：本模型为单次全波求解。只有当楔形/圆弧几何、材料界面、源注入、端口与 PML 边界均按 S04/S05 验证成立时，才可以说这些界面在域内的反射与多次往返已被本次求解计入；不无条件宣称『自动包含全部多次反射』，伪反射、截光与边界伪反射须按 S05/S09 排查后才入账本。正式端面为楔形+圆弧曲面，不借用 S04 B2 平面 Fresnel 的数值预期。不包含 LD 腔内反馈对源谱/模式的改变（固定源假设）。以文字+数值（返回源侧功率占比）明确该范围，结论不得超出。
6. 运行 BASE（LD974-WEDGE-BASE-001）与 LAT1（dx=+1.0 um 整体平移，含透镜；旋转/平移顺序与端面中心记录）。每 case 保存：参数快照哈希、模型 SHA、study/dataset、job_id、起止时间、DOF、效率、闭合、原始复场（FIELD_CONTRACT 元数据）。失败 case 保留 null+原因，不填 0。
7. 首次完整效率只是基线：不得命名"最优"，不得与任何公开 980 nm 文献数值互相校准以"证明"设计；形状/参数改动一律须 ADR（本版禁止）。

## 必交付与有限验收

规范模型 ld974_lensfiber_ewfd.mph（建议名，以冻结配置为准）与完整调用序列、BASE/LAT1 case 记录、全链功率账本与分母链、监视面/入纤截面复场、几何验证与重建回归记录、反射范围声明。G07a、G14 通过，且 S02/S03/S04/S05 已通过的门槛在最终模型语境下持续成立（引用其证据，不重跑其定义）。

## 失败处理

几何失败（自交叠/边厚非法）：fail-closed 在求解前拒绝，回 S01 参数层核对，不改冻结初值"绕过"。求解不收敛：先查网格与注入连续性，再按 SOLVER 分类登记；3 次无新证据停止该路径。闭合不达标：按 FIELD_CONTRACT 排查权重/法向/反向分量，不得放宽 G07a。效率异常高：优先怀疑账本重复计或模式误认，独立重投影后再报告。
